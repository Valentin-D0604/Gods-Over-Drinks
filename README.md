# Gods-Over-Drinks
Jeu de stratégie multijoueur sur Unity

Voici God over drinks ! Un jeu de stratégie multijoueur où la gestion de terrain et de vos ressources est ce qui vous apportera la victoire. 

Pour tester mon projet, télécharger le ZIP, avant de l'extraire et de lancer le jeu. Pour jouer dans les meilleures conditions en multijoueur, un compte Steam est nécessaire
